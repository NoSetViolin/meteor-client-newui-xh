# UI 绘制引擎

UI 现在使用独立的 SDF 形状管线，在 Minecraft 的 GPU 抽象上提交绘制。模块逻辑、设置持久化和鼠标命中区域沿用现有实现。

## 能力与接口

`GuiRenderer` 保留原有圆角接口，并增加：

- `roundedGradient(...)`：垂直渐变圆角矩形。
- `roundedOutline(...)`：沿圆角轮廓向内绘制的空心描边。
- `roundedShadow(...)`：带高斯衰减的软阴影，先于对应表面调用。
- `roundedBackdrop(...)`：从全窗口模糊纹理采样，通过圆角遮罩绘制毛玻璃。

所有坐标均为现有 GUI 使用的窗口像素坐标。圆角半径会限制在矩形短边的一半；非正尺寸和非有限形状参数不提交。边缘由着色器导数抗锯齿，不再取决于图标纹理分辨率。

`UiShapeRenderer` 将形状数据放入每顶点 56 字节的顶点格式。同类连续调用共享一个批次，切换管线、纹理、文字字号、透明度或裁剪区域时提交。着色器计算填充、描边和阴影，无需为每个控件分配独立 uniform。普通图片也按调用顺序绘制；原生物品和显式 `post` / `absolutePost` 仍按现有延后绘制语义执行。

## 主界面与设置

主界面及模块设置页共用整窗毛玻璃表面，替代原先侧栏的 29 次分段裁剪。无可用世界背景纹理时使用不透明渐变表面。暗色和亮色模式均保留；卡片和控件使用新的渐变与真实圆角描边。

界面品牌为 `XiaohSense`，侧栏使用统一的几何图标。主界面采用有描述的双列卡片、独立的标题与工具栏、滚动边缘淡出和受可用窗口尺寸约束的缩放。底部账户显示实际客户端用户名，并对过长文字省略。模块设置页共享品牌、字体和配色；配置复制与粘贴按钮独占一行，避免挤压标签。设置组的双列宽度超过内容区域时自动改为单列，保留控件的测量宽度与独立重置按钮。

这两种屏幕独立选择比例字体（优先 Segoe UI、Inter、Noto Sans、Arial，最后使用内置字体），保留中文回退字体。标题、正文和辅助文字使用不同字号；文字测量与渲染使用相同缩放。

Meteor 主题的 General 设置新增：

- `ui-effects`：默认 `High`，使用 blur 等级 10、较宽窗口阴影与开关发光；`Balanced` 使用 blur 等级 5 和较窄窗口阴影；`Off` 关闭现代界面的毛玻璃、窗口阴影及开关发光。
- `ui-animations`：默认开启，控制主界面导航选中、模块行悬停和开关滑动的平滑过渡。关闭后这些状态立即变化。

现代界面特效独立于 Blur 模块开关，其他屏幕仍使用原有 Blur 模块设置。HUD 和世界中的 3D 渲染未重做。

嵌套裁剪使用父子区域交集；透明度改变前提交旧批次，使文字、图形、线条及图片保持一致。Blur 的纹理在窗口尺寸变化时同时释放 view 和底层纹理，最小纹理尺寸为 1×1。

## 验证

构建：`./gradlew.bat build --offline`。

GPU 回归检查：`./tools/check-ui-shaders.ps1`。脚本适用于 Windows x64，要求 Java 25 或更高版本及支持 OpenGL 3.3 的驱动；首次运行从 Maven Central 下载 LWJGL 3.4.1 到忽略的 `build/ui-shader-check` 目录。测试创建隐藏窗口，直接编译项目中的两套着色器，并检查 24 项真实 GPU 像素结果。

本次在 RTX 4070 SUPER 上通过着色器编译、链接和全部像素检查，完整 Gradle 构建通过。构建仍存在第三方依赖的 `ReflectionSupport.Level.FULL` 缺失警告，GPU 测试在 Java 26 下有 LWJGL Unsafe 弃用提示。

实际 Minecraft 26.2 客户端已启动，并从游戏渲染目标捕获亮色、暗色、搜索结果、空结果和 Criticals 设置页截图。截图位于忽略的 `build/ui-preview` 目录。搜索通过实际键盘事件输入，检查了文字、图标、品牌、卡片、滚动裁剪和配置按钮布局。

另以 854×480 窗口捕获相同五种状态，截图位于 `build/ui-preview-small`，确认窗口自适应缩放后品牌、侧栏与工具栏均完整可见。

开发时可通过 JVM 属性 `-Dmeteor.ui.preview=true -Dmeteor.ui.preview.dir=<绝对输出目录>` 启用 `UiPreview`。它等待客户端初始化，依次打开上述五种界面、截图并自动退出；默认启动完全不启用。请为此使用独立的开发游戏目录，以免影响个人界面配置。

截图背景为标题全景，未完成世界中的毛玻璃、模块启停、拖动、下拉菜单、中文文字以及 Sodium / Iris 兼容性验证，也没有进行 FPS 基准测量。
