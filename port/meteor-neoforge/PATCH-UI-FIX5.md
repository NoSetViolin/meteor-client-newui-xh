# 菜单修复 fix5

Meteor 0.5.8-neoforge.5，Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21。

## 修复范围

1. Logo 在原有 30 × 30 设计尺寸上使用 7 单位半径、带抗锯齿的圆角纹理遮罩。用户提供的 JPG 资源内容不变。
2. 模块列表和右键配置界面使用共享窗口位置。进入配置、在配置中再次拖动、返回列表、关闭后重新打开都沿用本次游戏会话的位置；屏幕尺寸不足时约束在可见范围。移除配置页默认向左上偏移 10% 的逻辑；重新打开已有 screen 时刷新布局，避免沿用旧坐标。
3. 修复非现代编辑/列表页面中文空缺：旧自定义字体只打包固定字符范围，不含 CJK，而此前中文回退仅接入新模块列表和设置页。现在 MeteorGuiTheme 的其他菜单页也包装当前选定字体，以原版 Unicode 字体绘制中文字串并统一测量宽度。英文纯文本仍使用用户选定的字体。全局字体、HUD、模块、Sodium/Iris/Baritone 代码未改动。

## 验证

独立 NeoForge 实例仅从 mods 加载最终 jar，包含 Sodium、Iris（光影关闭）、Create、Petrolpark 和 Baritone。

- 修复前复现：旧编辑窗口中的中文标题、标签及输入内容完全不见，仅英文和数字保留。见 before/chinese-editor.png。
- 修复后检查：中文窗口标题、中文输入框、简体/繁体和中英混排均正常显示。见 after/meteor-11-ui-chinese-editor.png。
- 模块列表拖动后进入配置，实际面板 x/y 一致；配置页再次拖动后返回及重新打开，实际面板仍继承同一坐标。测试报告包含断言结果。
- 检查 logo 圆角和模块列表/设置页显示，Ins 呼出/关闭、搜索及返回路径通过。
- shadowJar 和严格 jar 检查通过；源码及校验值随包提供。对照 fix4 检查非 GUI 的运行代码字节一致（开发自检类除外）。

复测：`tools/run-release-test.ps1 -WithBaritone -UiOnly`。所有开发自检默认关闭，中文样例和测试操作不会在正常游戏中执行。窗口位置继承为会话内状态，本轮未新增跨游戏重启的位置配置。
